## 3. Runtime Framerate & Animation Budget (60 FPS)

To prevent dropped frames ("jank"), all animations adhere to the **16.6ms per frame budget**:

1. **Hardware-Accelerated Compositor Only:**
   - Background radial drifts use `transform: translate3d(...)` and `opacity`.
   - Card elevations use `transform: translateY(...)` and `box-shadow`.
   - Image zooms use `transform: scale(1.04)`.
   - **Zero forced reflows or layout recalculations** during animation execution.
2. **GPU Layer Promotion:**
   - Elements with continuous motion (`.hero-ambient-glow`, `RotatingGeometricMesh`, `.dual-arrow-badge`) are promoted to dedicated GPU compositor layers via `will-change: transform`.
3. **Memory Safety & Clean Unmounting:**
   - Kinetic components implement strict React `useEffect` cleanups (`cancelAnimationFrame`, `clearInterval`, and `clearTimeout`) to prevent memory leaks when navigating between routes.

## 4. Zero Layout Shift (CLS = 0.000)

Cumulative Layout Shift is zero due to:
- **Reserved Aspect Ratios:** All image tags specify explicit `width`, `height`, and `aspect-ratio` containers (`aspect-[4/3]`, `aspect-[16/10]`), preventing reflow as high-res images load.
- **Fixed Dimension Plaque & Hero Elements:** The executive practice plaque reserves its exact desktop footprint (`min-h-[460px]`).
- **Rotating Text Container Fixed Min-Height:** The service rotator reserves fixed inline height so alternating text labels (*Audit & Assurance*, *GST Compliance*, etc.) do not cause content below to shift.
